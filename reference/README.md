# reference

Old-project reference. Facts only; verify before relying; vocabulary and policies here are NOT requirements.

Everything under this folder was copied verbatim (or, where a file says so, extracted) from the scrapped plinth project, its evidence folder, and the owner-ruling memory notes. Nothing here was edited. See `/MANIFEST.tsv` (one row per file: destination, source, sha256, bytes, provenance).

Folders:
- `experiments/` - calibration-plate (coupon) records, plate photos, the H2 raw scoring matrix, coupon-derived physics notes.
- `owner-notes/` - Craig's rulings and field feedback, as written down during the old project (dates are in the file names).
- `datasheets/` - printer and resin vendor data and the vendor PDFs.
- `literature/` - literature notes and the primary PDFs.
- `formats/` - ChituBox file-format facts and the old independent-audit invariants.
- `models-and-jobs/` - the old job list of minis, mesh-classification measurements, the repair census.
- `engineering-evidence/` - a small set of retained analysis records (validator rethink, hollowing, profiling, bracing, old physics account).

Quality order when sources disagree: measured on this printer (plates, Craig's reads) > Craig's stated practice > vendor sheets > literature > old code or notes. Old code values are never evidence. The lessons that frame all of this are in `/docs/LESSONS.md`.
