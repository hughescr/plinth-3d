# History — superseded documents, kept for provenance

Documents that describe a state of the project that no longer exists. They
are here because the reasoning is worth being able to find again, not
because anything should be built from them.

Read nothing here as current. `docs/specs/` is the law, `docs/reference/`
holds findings that are still true, and this directory holds neither.

- `CLAUDE-CODE-KICKOFF-v4.md` — the brief that started the v4 rewrite of
  the support-placement engine. Superseded by the ratified specs in
  `docs/specs/` and by `skills/support-placement/references/design-v4.md`.
- `CODEX-KICKOFF.md` — the standing brief handed to the migration
  orchestrator. Every path it tells the reader to open first (`docs/
  rust-migration/`) has since moved, and the branch it names no longer
  exists. The numbered guides it points at are the `00`–`07` files in this
  journal's parent directory; read those instead.
